# Copenhagen + Iceland 2027

Static travel-journal website for a Copenhagen + Iceland trip (March 18–28, 2027).

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `copenhagen-iceland-2027`.
2. Upload **everything in this folder** to the repository root. `index.html` must stay at the top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. GitHub will show the public Pages URL after deployment.

## Edit the site

- `index.html` — Home
- `trip.html` — Trip plan
- `food.html` — Food + food map
- `map.html` — Route map
- `guide.html` — Travel guides
- `bookings.html` — Booking dashboard
- `saved.html` — Saved places
- `admin.html` — Editor UI prototype
- `assets/js/content.js` — Shared travel content/data
- `assets/css/site.css` — Site styling
- `assets/img/` — Images and map assets

## Privacy

Do not publish confirmation numbers, passport information, payment details, door codes, or other private booking credentials in a public GitHub Pages repository.
